battery_saver Энергосбережение Wi-Fi модуля 88x2cs (/sys/module/88x2cs/parameters/)
warning ПОЧЕМУ ПАДАЕТ WI-FI ПОСЛЕ ВЫКЛЮЧЕНИЯ КВАЗАРА И ЧТО ОТКЛЮЧИТЬ:
Когда сервисы Квазара (maind, quasar_launcher2) отключены или убиты скриптом, прекращается регулярный служебный опрос сетевого интерфейса. По умолчанию в ядре станции для модуля 88x2cs включено агрессивное энергосбережение, из-за чего чип RTL8822CS засыпает и перестает отвечать роутеру.

ЧТО ОБЯЗАТЕЛЬНО ВЫКЛЮЧИТЬ (УСТАНОВИТЬ В 0):
• rtw_power_mgnt = 0 — Главное энергосбережение чипа (по умолчанию 2 = Max PS). Обязательно установить в 0, чтобы чип оставался активным 24/7.
• rtw_ips_mode = 0 — Inactive Power Saving (IPS) (по умолчанию 1). Отключает засыпание чипа при паузах в передаче данных.
• rtw_smart_ps = 0 — Smart Power Saving (по умолчанию 2). Предотвращает задержки и выпадения пинга при стриминге музыки.
